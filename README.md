# Таверна — прототип на Godot

Серый (greybox) прототип игры «Таверна» по [дизайн-документу](https://claude.ai/artifact/5F99xx3EiwZvnkaz8H9brj).
Всё собрано из простых фигур (кубы, цилиндры, сферы), моделей и текстур нет. Мир строится кодом в `scripts/main.gd`.

## Как запустить

1. Установите [Godot 4.3](https://godotengine.org/download) (обычная версия, не .NET).
2. В менеджере проектов нажмите «Импорт» и выберите файл `project.godot` из этой папки.
3. Нажмите F5 (▶ «Запустить проект»).

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD | Ходьба (работает и на русской раскладке) |
| Пробел | Прыжок |
| Мышь | Осмотреться |
| E | Действие: взять, положить, отдать, поговорить, войти в портал |
| R | Сменить рецепт на верстаке (или на плитке после улучшения) |
| ЛКМ | Удар |
| Esc | Освободить курсор |

## Что есть в прототипе

- **Таверна в руинах**: главный зал, барная стойка, кухня, подсобка. Три стола завалены мусором — их расчищают метлой.
- **Кухня**: ящик с продуктами → стол для разделки (нарезка) → плитка (рагу). Самогонный аппарат делает самогон из продуктов.
- **Гости** приходят сами. Тем, кто у стойки, нужен самогон; тем, кто за столом, — еда, которую надо отнести к столу. Если гость долго ждёт, он уходит, и репутация падает.
- **Подсобка**: верстак инструментов (метла, молоток, украшения-улучшения) и верстак изобретений (синий огонь, фонарь, синяя лампа, слот-машина).
- **Улучшения как в Valheim**: украшение из ингредиентов с вылазок ставится к верстаку и поднимает его уровень. Медная вытяжка открывает грибной суп на плитке, змеевик ускоряет самогон, тиски открывают молоток, синяя лампа открывает слот-машину.
- **Квест Шампика**: потерянный фонарь → Поля роботов → рецепт синего огня → починка → свой фонарь → Сумеречный лес.
- **Бой**: роботы в полях (с них падают шестерёнки) и тени в лесу. При потере сознания вы очнётесь у таверны и потеряете часть монет.
- **Репутация открывает комнаты**: 5 — ВИП-комнаты (двойная оплата), 10 — концертный зал (+25% ко всем заказам), 15 — второй этаж (аренда комнат).
- **Поселение**: с молотком и 40 монетами на участках во дворе строятся дома, появляются жители, гости приходят чаще.

## Быстрое прохождение

1. Поговорите с Шампиком во дворе, затем идите в таверну и готовьте рагу и самогон для гостей.
2. Сделайте метлу (5 монет) и расчистите завалы.
3. Через оранжевый портал отправьтесь в Поля роботов, найдите фонарь и выбейте шестерёнки из роботов.
4. Отдайте фонарь Шампику, сделайте синий огонь, отдайте и его, затем сделайте себе фонарь.
5. Через фиолетовый портал идите в Сумеречный лес за светогрибами.

## Файлы

- `scripts/main.gd` — построение мира, состояние игры, кухня, верстаки, гости, квест, интерфейс.
- `scripts/player.gd` — игрок от первого лица.
- `scripts/customer.gd` — посетитель.
- `scripts/enemy.gd` — робот или тень.
